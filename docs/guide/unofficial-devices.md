# Unofficially supported devices/project

::: warning
In this page, there are kernels/projects for GKI/non-GKI devices supporting BakaSU maintained by other developers.
:::

::: warning
This page is intended only to help you find the source code/project corresponding to your device. It **DOES NOT** mean that the source code/project has been reviewed by BakaSU developers. You should use it at your own risk.
:::

::: info
You can [submit a issue](https://github.com/BakaSU/BakaSU.github.io/issues) to the document repo to add devices you maintaining.
:::
